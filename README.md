# 买量游戏核玩助手（ua-core-gameplay-assistant）

从 9 个核玩工具仓库提取的核心玩法（核玩）规则知识库，外加所有核玩工具共同遵守的《核玩工具通用规范》。用于规则问答、广告玩法复刻、关卡/可解性设计、自动通关策略参考，以及开发新的核玩素材工具。

## 知识范围（2026-11-08 快照）

覆盖 9 类核玩：麻将消除、打螺丝、咖啡分拣、方块射击、祖玛、拔钉救人、箭头挪出、体素射击、圆环传送带。规则提取自对应工具的源码快照；通用规范取自最新版《核玩工具通用规范》（含 §7 控制台分层、§8 缺口安全区）。

**隐私约束：插件内容不写来源仓库地址/链接，证据只保留相对路径（文件:行号）。**

## 结构

- `skills/ua-core-gameplay/SKILL.md` — 主 Skill：路由到对应游戏规则，约束回答与开发行为。
- `skills/ua-core-gameplay/references/<game>.md` — 每个游戏的玩法规则、判定逻辑、胜负条件、关卡生成与可解性、自动通关策略、关键默认参数、已知差异，附源码文件:行号证据（路径相对各仓库根）。
- `skills/ua-core-gameplay/references/toolkit-standard.md` — 通用规范：单文件构建、按钮/设置键名、AE/3D/H5 导出包结构、渠道 CTA、手指与鼠标规则、测试要求。

## 使用

安装后在对话中直接问，例如：
- 「麻将的被压判定规则是什么？」「螺丝工具的 screwBlock 规则细节」
- 「我要做一个新的核玩工具，通用规范有哪些硬性要求？」
- 「咖啡分拣的关卡怎么保证有解？」「祖玛的连击是怎么触发的？」

## 注意

- references 是上述快照日期的知识，仓库会持续演进；涉及精确数值/判定时，若本地有对应仓库，应以当前代码为准核对。
- 规则中标注「工具补全」的部分是参考视频未确认、由工具按同类玩法补全的设计，不是原广告的确证行为。
- 未收录：各仓库 `ref/ANALYSIS.md` 的逐帧测量全文、外观/美术参数大全、截图与视频素材（体积大且易过时，需要时回原仓库查阅）。
- 已知文档冲突已按较新事实修正：H5 试玩 `h5AutoPlay` 默认 **false**（旧规范表格写 true，已被 §5.3 与各仓库最新版本推翻）；ring-belt 的 AE/3D/H5 导出**已实现**（其 README「第二阶段未做」已过时）。

## 维护迭代

- 规则知识持续迭代：工具规则演进或确认新事实时，更新对应 references 文件、升 `plugin.json` 版本号，重新打包安装。
- 新增游戏：在 `references/` 加规则文件，并在 SKILL.md 路由表加一行。
- 每次发布前自检：manifest 可解析、引用链接存在、内容不含来源仓库地址/凭据。

## 安装

源码目录可直接打包安装：`zip -r ua-core-gameplay-assistant.zip ua-core-gameplay-assistant -x '*.DS_Store'`，然后在 Qoder 扩展视图导入 ZIP；或让 Qoder 助手执行安装流程。
