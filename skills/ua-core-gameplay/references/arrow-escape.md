# 箭头挪出

2026-11-08 源码快照，规则以代码为准；证据路径相对工具仓库根。关键源码：`src/game.js`（判定/求解/生成）、`src/refseq.js`（参考序列）、`src/level_ref.json`（参考关）、`src/settings.js`。

**玩法定位**：「箭头挪出」广告——网格铺满带箭头折线拼成哆啦A梦，点线若箭头前方无阻则沿自身路径蛇形滑出，全部挪空获胜。顺序自由。

## 关卡结构

- 参考关 48 列×50 行、200 条互不重叠折线（共 1704 格，单线 2~61 点；青 120/绿 55/白 25）。
- 线=尾→头的相邻格点序列，**箭头方向=最后一段方向**；关卡 JSON `{name,cols,rows,lines:[{c,p:[[col,row],…]}]}`。
- 画面网格原点 (39.43,366.96)、格距 13.64px，画布 720×1280（game.js:7）。

## 操作与判定

- **可挪判定**：从箭头头部沿方向逐格前进直到关卡边界，不遇到任何其他线的格（自身格排除）；blockerOf 返回首个挡路线 {id, 距离 k}（game.js:28-31）。
- 点可挪线（仅 idle 态可点）：**立即从占用表删除其全部格**（其他线即刻解锁）；滑出路径=自身折线+过头后沿箭头方向的直线延长；s 以初速 2 格/秒、加速度 300 格/秒²、上限 72 格/秒推进；尾部离开当前镜头视野+1.2 格才算 gone（game.js:71-98）。
- **被挡反馈**（默认 ref 风格）：线变白并标记，沿路径冲到 k−bumpStopGap(0.5) 格（箭尖碰到挡路线），挡路线闪白 0.15s，停顿 0.1s 后 0.2s 退回原位；白色标记保持到成功挪出；前 3 次被挡有边框红光（0.3/0.23/0.1s），之后不再出现。可选 shake=变红沿箭头抖 0.3s、不标记（game.js:75-91）。
- 命中判定：最近线段距离 ≤hitR 0.6 格距，箭头头部有额外吸附（game.js:61-70）。

## 胜负

所有线 gone→win（game.js:94-95）；**无倒计时、无失败态**。不可解关卡无失败流程（状态栏警告、编辑器标红），自动求解会停滞等待。

## 生成与可解性

- normalizeLevel 校验 ≥2 点、步步相邻、不自交/互叠。
- **solveLevel 贪心**反复移除无阻线——挪走一条只会让别的线更容易挪（单调性），故贪心即可判定可解并给出顺序/卡死集合（game.js:13-39）。
- 图片生成关：透明 PNG 缩到 genCols=40 列，alpha>0.5 格上随机游走铺 2~14 格线（55% 概率延续原方向），孤立格并入邻线端点；再 ≤60 轮修复：卡死线反向/从中间切开/40 轮后删除（game.js:112-140）。
- 编辑器：拖动画线（尾→头）、删除/改色/反向、实时可解检查（卡死线标红）、JSON 导入导出。

## 自动通关 AI

- 默认 **ref**=逐帧重放参考视频 **27 次点击（含 5 次被挡：4.4/10.95/20.62/40.22/42.38s）**+1.647 倍放大与 4 次平移+0.1s 采样手指轨迹，播完转求解器清空（refseq.js:3-24）。ref 序列仅对内置参考关生效，其他关自动退回 solver。
- solver=只点可挪线（0 次点错，优先视野内离手指最近）；solverMiss=以 missChance 0.15 故意点被挡线。按游戏时间确定性调度（RNG 种子 12345）。
